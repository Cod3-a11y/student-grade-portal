Student Grade Portal

A web-based Student Grade Portal developed as part of a second-year BSIT web development activity. The project demonstrates a role-based academic management interface for students, teachers, and administrators.

Features

Role-Based Dashboards

- Student: View general average, subjects, passing status, LRN, and grade records.
- Teacher: View subject-specific records, access student information, and encode or edit grades.
- Admin: View system summaries and manage academic records, students, teachers, and subjects.

Grade Management

- Displays quarterly grades (Q1–Q4), final grades, and posting status.
- Calculates and displays student grade averages.
- Provides grade-record search and editing tools.
- Supports grade-record deletion for administrators.

Student and Academic Records

- View and search student records.
- Add student records.
- View teacher and subject information.
- Access role-specific profile pages.

Interface

- Dashboard layout with navigation sidebar.
- Light and dark theme preference.
- Responsive interface for easier navigation.
- Sample academic data for demonstration.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage for prototype data persistence

How to Run Locally

1. Download or clone this repository.
2. Open "index.html" in a web browser.
3. Sign in using the demonstration accounts configured in the project.
4. Explore the dashboard and available features for each role.

Project Files

- "index.html" — Main portal interface.
- "StudentPortalStyle.css" — Styling and layout.
- "StudentPortalScript.js" — Role-based interface, grade management, and application logic.

Data and Security Notes

This project is an educational prototype that stores its data in the browser using "localStorage". It does not use a production database or server-side authentication. Its demonstration data and login behavior should not be treated as a secure school information system.

Purpose

The project demonstrates how HTML, CSS, and JavaScript can be used to build a role-based academic portal with grade viewing, record management, and interactive dashboards.
